# Design

- Keep `Modal` props; render an HTML `dialog` through a portal and call `showModal()`. Browser top-layer ordering and inertness unify paint and interaction. Stop modal key events before workbench listeners. Compute tab stops on each key press. Observe removal/visibility changes only within the dialog, retaining adjacent focus candidates and a trigger fallback.
- Scope layout to `.forms-modal`: header/footer remain fixed in the flex layout, form/body can shrink, and only body content scrolls. JSON description, editor and errors share that body. Body scroll locking depends on an open forms dialog, so overlapping close order needs no global counter.
- Keep exported `NumberInput` and `MinuteInput` contracts. A local `NumericInput` stores raw text plus its last external value. A pure parser enforces finite decimal/exponent syntax, inclusive bounds and zero-anchored increments. Change edits text; blur/Enter commits only a valid changed business value. Native custom validity blocks form submission. Optional inputs additionally allow undefined. Minute editing uses a 0.0001-minute step matching the existing four-decimal display, instead of the previous 0.1 step that conflicted with sub-minute source precision; conversion still rounds to milliseconds.
- Key Inspector fieldsets by plan/entity identity. Numeric fields reset on external numeric change without discarding a draft when a sibling field changes. Local bilingual error messages combine with Field hint descriptions.
- Scenario/Resources Apply use forms. Both Resources panels stay mounted. Resources validates before applying, reveals an invalid hidden panel and then focuses its field. There is no App integration or D import.
- `FieldGroup` uses fieldset/legend; individual checkbox labels remain siblings. Default Field single-control labeling stays compatible.
- Real application browser cases use A0's production subpath setup. Until A0 enters integration, a separate detached validation worktree overlays B sources onto A0. Only that disposable configuration's port is changed from 4178 to 4183 for concurrent sessions. No shared configuration or dependency change is included in B.

References: [WAI dialog pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/), [WAI tabs pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/), [Playwright web server](https://playwright.dev/docs/test-webserver).
